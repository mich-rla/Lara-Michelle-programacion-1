¿Cómo clonar y utilizar el repositorio?

Para clonar el repositorio en otra computadora se deben seguir estos pasos:

1. Instalar Git y Visual Studio Code.
2. Abrir Visual Studio Code.
3. Seleccionar Git: Clone desde la paleta de comandos.
4. Copiar y pegar el enlace del repositorio de GitHub.
5. Elegir la ubicación donde se quiere guardar el repositorio.
6. Abrir la carpeta clonada en Visual Studio Code.
7. Realizar las prácticas o proyectos dentro de las carpetas correspondientes.
8. Guardar los cambios y utilizar Git para hacer "commit" y posteriormente "push" para subirlos a GitHub.
